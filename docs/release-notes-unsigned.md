> [!NOTE]
> **Gezik is signed on Windows and macOS.** The files are the ones built by this repository's GitHub Actions; check them against `SHA256SUMS.txt`.
>
> - **Windows:** signed by Wenlar LLC. The certificate is new, so SmartScreen may still say "Windows protected your PC" for a while; choose **More info ▸ Run anyway**.
> - **macOS:** signed with a Developer ID and notarized by Apple; it opens without a warning.
> - **Linux:** no warning; make the file executable if needed (`chmod +x gezik-*.AppImage`).
