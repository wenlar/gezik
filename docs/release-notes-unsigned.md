> [!WARNING]
> **These builds are not signed yet.** Your system will warn you the first time you open Gezik. The files are the ones built by this repository's GitHub Actions; check them against `SHA256SUMS.txt`.
>
> - **Windows:** SmartScreen may say "Windows protected your PC". Choose **More info ▸ Run anyway**. Some antivirus programs may also ask.
> - **macOS:** Gatekeeper says Gezik "cannot be opened because Apple cannot check it". Open **System Settings ▸ Privacy & Security**, scroll to Security and click **Open Anyway** next to Gezik, then confirm. (On older macOS: right-click Gezik ▸ Open.)
> - **Linux:** no warning; make the file executable if needed.
>
> Signed builds (Apple notarization, Windows code signing) will come in a later release.
