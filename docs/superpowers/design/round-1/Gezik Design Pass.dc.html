Component notes (this turn)
• Tab (tab-bar.slint): one Rectangle + icon Path + Text + close button + 2 px indicator Rectangle. In 1b the indicator is the same element moved to the bottom edge. Free/Cheap.
• Row: file list, sidebar, menu line, operations/drop-stack share one highlight recipe: background = selection | hover | transparent, plus an inset 2 px focus-ring border for the current item. No per-row shadow or gradient. Free.
• Sheet (1a only): one extra Rectangle with radius and border around list + header. Cheap.
• Status bar segments (1b only): 1 px Rectangles between cells, using border. Cheap.
• Scrollbar: replaces std-widgets' ListView bar with a 6 px thumb (scrollbar / scrollbar-hover), no track. Cheap; removes a source of system colours.
• Section labels: stored as literal uppercase strings (“PINNED”, “SABİTLENENLER”), never uppercased at runtime, so Turkish İ/ı stay correct.
