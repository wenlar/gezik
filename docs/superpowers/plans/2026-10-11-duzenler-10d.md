# Düzenler 10d (Gruplama: tür, tarih, boyut; kapanır grup başlıkları) — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dosya listesinde (liste ve ızgara; klasör, arama sonuçları, düz görünüm, çöp) türe, tarihe ya da boyuta göre Explorer kovalarıyla gruplama: grup başına bir başlık satırı (`Today (12)`), tıklanınca grup kapanır/açılır; klavye başlıkları atlar, seçim yalnız görünen öğelerdir; gruplama `views.toml`'da klasör başına, `[view] group` varsayılanı `none`.

**Architecture:** Saf çekirdek iki parça: `gezik-core/src/group.rs` (yeni: `GroupBy`, Explorer'ın tarih ve boyut kovaları, `DateBounds` — yerel gece yarıları bir kez hesaplanır, satır başına yalnız karşılaştırma —, `Grouping::ranks` ile sıralamanın birincil anahtarı, `spans` ile sıralı satırlardan grup aralıkları) ve `gezik-core/src/layout.rs`'e `Span`/`Lines` (başlık + hücre satırları: satır sayısı, satır → başlık/hücreler, öğe → satır, lastik bant, ok tuşları). `sort.rs` grup sırasını birincil anahtar olarak alır (`sort_entries_grouped`, `sort_rows_grouped`). Uygulama tarafında `ViewData` yalnız `groups: Vec<Span>` ve `group_keys: Vec<GroupKey>` tutar (öğe başına ek bellek yok); `ItemsModel` başlıkları model satırı olarak verir (sanal liste sanal kalır, iç içe repeater yok); `file-view.slint` başlık satırını çizer ve satır/sütun hesabını Rust'tan iki `pure callback` ile alır.

**Tech Stack:** Rust 2024 (rustc 1.99), Slint 1.18, `toml`/`toml_edit` (var). Yeni dış crate yok; `gezik-core` bağımlılıksız kalır.

**Spec:** `docs/superpowers/specs/2026-10-11-duzenler-design.md` (§1 "Gruplama (10d)" ve "Hafiflik"; §6 tamamı; §7.3 "Gruplama sütun kipinde uygulanmaz" (10e'nin işi); §10.1 `[view] group`; §10.2 `group-none`…`group-size`; §10.3 View ▸ `Group By ▸`, liste başlık menüsü, kimlikler 2000–2011; §11 "Gruplama" satırı; §12 10d satırı; §13 sıra 1 ve §13.1 10d; §14.3; §14.4 "çöpte gruplama", "OneDrive köklerinde gruplama"; §16 "Gruplama sütun kipinde yok"; §17 karar 19, 20, 21, 39, 40). ## Spec'ten sapmalar ve netleştirmeler (kararlar; soru sorulmadı)

1. **Grupların sırası ve yön.** Kanonik sıra spec'inki: türler adla (doğal sıra), tarihler yeniden eskiye, boyutlar büyükten küçüğe. Sıralama `Desc` olunca gruplar ters döner — **ama** grup kendi sütunuyla sıralanıyorsa (tarih grubu + `Modified`/`Created` sıralaması, boyut grubu + `Size` sıralaması) gruplar o sütunun yönünü izler: `Modified desc` → `Today` başta, `Modified asc` → `A long time ago` başta; `Size asc` → `Empty` başta. *Gerekçe:* spec'in "sıralama yönü ters dönünce gruplar da ters döner" kuralı ad sıralamasında doğru, ama kendi sütununda grup sırası ile grup içi sıra çelişirdi (spec'in kendi örneği `sort = "modified"`, `sort-dir = "desc"`, `group = "date"` en yeniyi başta bekler).
2. **`folders-first` açıkken klasör grubu her yönde başta:** tür gruplamasında klasör satırlarının grup(lar)ı, boyut gruplamasında boyutu bilinmeyen klasörlerin `Folders` grubu. Tarih gruplamasında klasörler tarihlerinin grubundadır (Explorer gibi), grup içinde başta. `folders-first` kapalıyken `Folders` kanonik sırada en sonda (sonra yön kuralı).
3. **Tarih kovaları ve yerel saat.** Kovalar önceliğe göre denenir: `Later` (yarından sonrası; spec'te yok — saati ileri giden dosyalar `Today`'e karışmasın diye), `Today`, `Yesterday`, `Earlier this week`, `Last week`, `Earlier this month`, `Last month`, `Earlier this year`, son 9 yılın her biri (`2025` … `2017`), `A long time ago` (10 yıl ve öncesi), `No date`. Sınırlar **yerel gece yarılarıdır**; `DateBounds::new` her sınırı bir kez hesaplar (bugünün gece yarısından gün kaydırma + yaz saati düzeltmesi, `local_date_parts` ile), satır başına yalnız `SystemTime` karşılaştırması kalır. **Hafta Pazartesi başlar** (yerel ayarın ilk günü okunmaz; `shortcut:` yorumu). Sınırlar sıralama anında hesaplanır ve `View`'de saklanır (gruplar ile sıra aynı sınırlardan); açıkken gün dönerse gruplar bir sonraki sıralamada/yenilemede güncellenir (zamanlayıcı yok).
4. **Tür grubu adı Type sütununun metni** (`type_name_of`, sistemin adı geldikçe; Windows'ta klasörler `File folder`, macOS'ta `Folder`). Sistem adları geldikçe bugünkü `resort_soon` (150 ms) grup tür ise de çalışır. Arama sonuçları bugün türü Gezik'in yedek adlarıyla sıralar; gruplar da onlarla (aynı ad iki yerde).
5. **Boyut kovaları ikili:** `Empty` (0), `Tiny` (< 16 KiB), `Small` (< 1 MiB), `Medium` (< 128 MiB), `Large` (< 1 GiB), `Huge` (< 4 GiB), `Gigantic`; boyutu hesaplanmış klasör kendi kovasında, bilinmeyen ya da yoldaki `Folders`'ta. Klasör boyutları geldikçe (`folder_sizes`) grup boyut ise bugünkü `resort_in_place` yolu çalışır (`sorted_by_size` gruba da bakar).
6. **Izgarada başlık bir hücre satırı yüksekliğindedir** (spec §6.2 "bir hücre satırını kaplar"); metin satırın altında, üstü boşluktur. Böylece bütün satırlar aynı yükseklikte kalır ve bugünkü bütün `satır × item-height` hesapları (kaydırma, görünür satırlar, sürükleme, lastik bant) değişmez. Listede başlık bir satır (`Theme.row-height`). `shortcut:` yorumu: ince ızgara başlığı, satır başına yükseklik gerekir.
7. **`ItemRow` iki alan alır:** `header: string` (sayıyla birlikte: `Today (12)`) ve `collapsed: bool`. Spec'in `count` alanı yazılmaz (sayı başlık metnindedir). Başlık satırının `first`'ü grubun ilk öğesinin numarasıdır (gruplar boş değildir, numara gruba tektir); `cells` boş.
8. **Menü kimlikleri:** spec'in `GROUP_NONE` adı `context_menu.rs`'te kenar çubuğu iğne gruplarının `GROUP_NONE = 1202`'siyle çakışır: adlar `GROUP_BY_NONE`, `GROUP_BY_TYPE`, `GROUP_BY_DATE`, `GROUP_BY_SIZE` (2000–2003; 2004–2009 etiket ve gelecek için boş), `COLLAPSE_GROUPS` 2010, `EXPAND_GROUPS` 2011. Sayılar spec'inkiler.
9. **`Action::ALL` 85 → 89** (spec §10.2'nin "85 → 93 → 94 → 98" dizisi 10b/10c'nin önce geleceğini varsayar; 10d ilk birleşen parça). Sonraki parçalar sayıyı birleşme sırasına göre artırır; sekiz `assert_eq!(Action::ALL.len(), …)` satırı her birleşmede güncellenir. Eylem başlıkları: `Group by None`, `Group by Type`, `Group by Date`, `Group by Size`.
10. **Arama sonuçları ve düz görünüm** yalnız bu gruplamayla **sıralandıktan sonra** gruplu gösterilir (`ResultSet::sorted_by` artık `(SortSpec, bool, GroupBy)`); arama sürerken gelen partiler sırasız olduğundan liste düz kalır, arama bitip sıralama gelince başlıklar çıkar. Tek sonuçlu küme sıralanmadığı için başlıksızdır (`shortcut:` yorumu). Çöpte `Modified` sütunu zaten silinme tarihidir (`trash_view::to_set`), tarih grubu ondan.
11. **Kapanan grup:** içindeki seçim kalkar; odak içindeyse sonraki görünen öğeye (sondaysa öncekine, hiç yoksa odak yok) geçer — `Delete`/`Enter`/`F2` hiçbir zaman görünmeyen öğeye gitmez (seçim yokken odağa düşen eylemler dahil). Shift+ok ile kapalı grubun üstünden geçen aralık da yalnız görünenleri seçer (her seçim değişiminden sonra kapalı aralıklar düşülür). Kapalı grupların durumu `View`'de anahtarlarıyla, yalnız o klasör gösterildiği sürece (aynı klasörün yeniden okunması korur; başka klasör, arama ya da gruplama değişimi siler).
12. **Başlıklar odak almaz;** klavyeyle tek grup açılıp kapanmaz (spec'te yok). Ekran okuyucu başlığa `button` rolü ve varsayılan eylemle ulaşır (`accessible-action-default` grubu açar/kapar).
13. **This PC (sürücüler) gruplanmaz;** ayar korunur, klasöre geçince geri gelir.
14. **Sıralama maliyeti:** grup sırası (`ranks`) sıralamadan önce ayrı bir geçişte hesaplanır (satır başına bir anahtar; dosya sistemi çağrısı yok); grup aralıkları (`spans`) gösterilen liste üzerinde ikinci bir doğrusal geçiş. Ölçüt (spec §1, §12): **tarih ve boyut** gruplu sıralama + aralıklar ≤ aynı sıralamanın gruplamasız süresinin 1,2 katı; **tür** gruplaması satır başına tür adı ister (Type sütunuyla sıralamanın bugünkü maliyeti), ölçütü "tür gruplu ad sıralaması ≤ gruplamasız **tür** sıralamasının 1,2 katı"dır; tür gruplu ad sıralamasının gruplamasız ad sıralamasına oranı notlara yazılır.
15. **macOS menü çubuğu:** View ▸ `Group By ▸ None / Type / Date / Size` işaretsiz öğeler (her öğe için yeni kök özelliği eklenmez); işaretli seçim View düğmesinin menüsündedir. Başlıkları eylem başlıklarından farklıdır ve `the_menu_bar_titles_are_the_actions_titles`'ta `ViewList`/`ViewGrid` gibi muaf.
16. **`stress.ps1 -Group <type|date|size>`:** geçici bir `GEZIK_CONFIG_DIR`'e `[view] group` yazar; 100.000 öğede gruplu/gruplamasız bellek ve kaydırma CPU'su aynı betikle ölçülür. Taban exe'nin kopyası (`target/gezik-base.exe`) `-Exe` ile karşılaştırılır.
17. **Denetim listeleri numaraları:** macOS listesi `master`'da 160'a kadar; açık dallar 9b8 161–167'yi, 9b9/9b10 sonrakileri alır. **10d'nin macOS maddeleri 200'den, Linux maddeleri 150'den** başlar. **Yeniden numaralama kuralı:** numaralar birleşmede değiştirilmez; bir dalın aralığı daha önce birleşmiş bir dalınkiyle çakışırsa sonra birleşen dal kendi maddelerini bir sonraki boş onluğa kaydırır ve sonuç dosyasında eski numarayı parantez içinde yazar; aradaki boş numaralar doldurulmaz.

    /// Days since 1970 → (year, month, day) (Howard Hinnant's `civil_from_days`).
    fn civil(days: i64) -> (i32, u8, u8) {
        let z = days + 719_468;
        let era = z.div_euclid(146_097);
        let doe = z.rem_euclid(146_097);
        let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365;

        let m = (if mp < 10 { mp + 3 } else { mp - 9 }) as u8;
        let y = (yoe + era * 400) as i32;

    }

/// Where each date bucket starts, as times: local midnights worked out once (a sort), so each
/// row costs only comparisons.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct DateBounds {
    year: i32,
    /// Tried in this order: the first start at or before a time is its bucket.
    starts: Vec<(DateGroup, SystemTime)>,
}

/// Seconds since 1970 (negative before), whole seconds down.
fn secs(t: SystemTime) -> i64 {
    match t.duration_since(UNIX_EPOCH) {
        Ok(d) => i64::try_from(d.as_secs()).unwrap_or(i64::MAX),
        Err(e) => -i64::try_from(e.duration().as_secs()).unwrap_or(i64::MAX) - i64::from(e.duration().subsec_nanos() > 0),
    }
}

fn at(secs: i64) -> SystemTime {
    let d = Duration::from_secs(secs.unsigned_abs());
    if secs >= 0 { UNIX_EPOCH + d } else { UNIX_EPOCH - d }
}

fn clock_secs(p: &DateParts) -> i64 {
    i64::from(p.hour) * 3600 + i64::from(p.minute) * 60 + i64::from(p.second)
}

fn first_of(year: i32, month: u8) -> i64 {
    crate::view::day_number(&DateParts { year, month, day: 1, ..Default::default() })
}

impl DateBounds {
    /// The buckets as seen at `now`; `local` gives a time's local date and clock
    /// (`gezik_platform::local_date_parts`). If it cannot, there are no buckets: every dated
    /// row is `LongAgo`.
    pub fn new(now: SystemTime, local: &dyn Fn(SystemTime) -> Option<DateParts>) -> DateBounds {
        let Some(today) = local(now) else { return DateBounds::default() };
        let day = crate::view::day_number(&today);
        let midnight = secs(now) - clock_secs(&today);
        // The start of local day `d`: today's midnight moved by whole days, then put right
        // where a daylight-saving change in between moved the clock.
        let start = |d: i64| {
            let guess = midnight + (d - day) * 86_400;
            match local(at(guess)) {
                Some(p) => at(guess - (crate::view::day_number(&p) - d) * 86_400 - clock_secs(&p)),
                None => at(guess),
            }
        };
        // 0: Monday (1970-01-01 was a Thursday). shortcut: weeks start on Monday everywhere;
        // read the locale's first day if users ask for Sunday weeks.
        let weekday = (day + 3).rem_euclid(7);
        let (y, m) = (today.year, today.month);
        let (last_y, last_m) = if m == 1 { (y - 1, 12) } else { (y, m - 1) };
        let mut starts = vec![
            (DateGroup::Later, start(day + 1)),
            (DateGroup::Today, start(day)),
            (DateGroup::Yesterday, start(day - 1)),
            (DateGroup::EarlierThisWeek, start(day - weekday)),
            (DateGroup::LastWeek, start(day - weekday - 7)),
            (DateGroup::EarlierThisMonth, start(first_of(y, m))),
            (DateGroup::LastMonth, start(first_of(last_y, last_m))),
            (DateGroup::EarlierThisYear, start(first_of(y, 1))),
        ];
        starts.extend((1..YEARS).map(|back| (DateGroup::Year(y - back), start(first_of(y - back, 1)))));
        DateBounds { year: y, starts }
    }

    /// The bucket of a row's time; `None`: `NoDate`.
    pub fn group(&self, time: Option<SystemTime>) -> DateGroup {
        let Some(time) = time else { return DateGroup::NoDate };
        self.starts.iter().find(|(_, start)| time >= *start).map_or(DateGroup::LongAgo, |(g, _)| *g)
    }

    /// Newest first.
    fn place(&self, g: DateGroup) -> u32 {
        match g {
            DateGroup::Later => 0,
            DateGroup::Today => 1,
            DateGroup::Yesterday => 2,
            DateGroup::EarlierThisWeek => 3,
            DateGroup::LastWeek => 4,
            DateGroup::EarlierThisMonth => 5,
            DateGroup::LastMonth => 6,
            DateGroup::EarlierThisYear => 7,
            DateGroup::Year(y) => 8 + u32::try_from(self.year - 1 - y).unwrap_or(0),
            DateGroup::LongAgo => 100,
            DateGroup::NoDate => 101,
        }
    }
}

/// A row's size bucket: a file's size, a folder's worked-out total, else `Folders`.
pub fn size_group(e: &Entry) -> SizeGroup {
    const KB: u64 = 1024;
    const MB: u64 = KB * KB;
    const GB: u64 = MB * KB;
    match e.known_size() {
        None => SizeGroup::Folders,
        Some(0) => SizeGroup::Empty,
        Some(b) if b < 16 * KB => SizeGroup::Tiny,
        Some(b) if b < MB => SizeGroup::Small,
        Some(b) if b < 128 * MB => SizeGroup::Medium,
        Some(b) if b < GB => SizeGroup::Large,
        Some(b) if b < 4 * GB => SizeGroup::Huge,
        Some(_) => SizeGroup::Gigantic,
    }
}

/// How a list is grouped: the grouping, the sort it goes with, and what keys need.
pub struct Grouping<'a> {
    pub by: GroupBy,
    pub spec: SortSpec,
    pub folders_first: bool,
    pub dates: &'a DateBounds,
    /// The Type column's text (the same function the sort uses).
    pub type_name: &'a dyn Fn(&Entry) -> String,
}

/// Ranks below this go first in either direction (the folders' group with folders-first).
const HALF: u32 = 1 << 31;

impl Grouping<'_> {
    /// Row `e`'s group; `None` when not grouped.
    pub fn key(&self, e: &Entry) -> Option<GroupKey> {
        Some(match self.by {
            GroupBy::None => return None,
            GroupBy::Type => GroupKey::Type((self.type_name)(e)),
            GroupBy::Date => {
                GroupKey::Date(self.dates.group(if self.spec.key == SortKey::Created { e.created } else { e.modified }))
            }
            GroupBy::Size => GroupKey::Size(size_group(e)),
        })
    }

    /// Whether the groups go against their canonical order (sapma 1): a grouping sorted by its
    /// own column follows that column's direction, any other sort turns them round when
    /// descending.
    fn reversed(&self) -> bool {
        let own = matches!(
            (self.by, self.spec.key),
            (GroupBy::Date, SortKey::Modified | SortKey::Created) | (GroupBy::Size, SortKey::Size)
        );
        if own { self.spec.dir == SortDir::Asc } else { self.spec.dir == SortDir::Desc }
    }

    /// The folders' group goes first whatever the direction (folders-first; sapma 2).
    fn pinned(&self, e: &Entry, key: &GroupKey) -> bool {
        self.folders_first
            && match key {
                GroupKey::Type(_) => e.is_dir,
                GroupKey::Size(g) => *g == SizeGroup::Folders,
                GroupKey::Date(_) => false,
            }
    }

    /// Each row's place among the groups, smaller first: the sort's first key. Empty when not
    /// grouped. Type names are put in natural order once all are known.
    pub fn ranks<'e>(&self, len: usize, entry: &dyn Fn(usize) -> Cow<'e, Entry>) -> Vec<u32> {
        let mut names: HashMap<String, u32> = HashMap::new();
        let mut rows: Vec<(bool, u32)> = Vec::with_capacity(len);
        for i in 0..len {
            let e = entry(i);
            let Some(key) = self.key(&e) else { return Vec::new() };
            let pinned = self.pinned(&e, &key);
            let place = match key {
                GroupKey::Type(name) => {
                    let next = u32::try_from(names.len()).unwrap_or(u32::MAX);
                    *names.entry(name).or_insert(next)
                }
                GroupKey::Date(g) => self.dates.place(g),
                GroupKey::Size(g) => g as u32,
            };
            rows.push((pinned, place));
        }
        if !names.is_empty() {
            let mut sorted: Vec<(&String, &u32)> = names.iter().collect();
            sorted.sort_by(|a, b| natural_cmp(a.0, b.0));
            let mut by_id = vec![0u32; names.len()];
            for (rank, (_, id)) in sorted.iter().enumerate() {
                by_id[**id as usize] = u32::try_from(rank).unwrap_or(u32::MAX);
            }
            for row in &mut rows {
                row.1 = by_id[row.1 as usize];
            }
        }
        let reversed = self.reversed();
        rows.into_iter()
            .map(|(pinned, place)| match (pinned, reversed) {
                (true, _) => place.min(HALF - 1),
                (false, false) => HALF + place.min(HALF - 1),
                (false, true) => u32::MAX - place.min(HALF - 1),
            })
            .collect()
    }
}

/// The groups of rows sorted with `grouping`: each run of rows with the same key, closed if
/// `collapsed` says so, and its key. Rows past what `entry` gives end it. Not grouped: none.
pub fn spans<'e>(
    len: usize,
    entry: &dyn Fn(usize) -> Option<Cow<'e, Entry>>,
    grouping: &Grouping<'_>,
    collapsed: &dyn Fn(&GroupKey) -> bool,
) -> (Vec<Span>, Vec<GroupKey>) {
    let (mut spans, mut keys): (Vec<Span>, Vec<GroupKey>) = (Vec::new(), Vec::new());
    for i in 0..len {
        let Some(e) = entry(i) else { break };
        let Some(key) = grouping.key(&e) else { return (Vec::new(), Vec::new()) };
        match (spans.last_mut(), keys.last()) {
            (Some(span), Some(last)) if *last == key => span.len += 1,
            _ => {
                spans.push(Span { start: i, len: 1, collapsed: collapsed(&key) });
                keys.push(key);
            }
        }
    }
    (spans, keys)
}

pub struct Span {

    }

/// A line of a grouped view: group `g`'s header, or entries.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Line {
    Header(usize),
    Cells(Range<usize>),
}

/// The lines of a grouped view: per group a header line, then its entries `per_row` a line
/// (none while closed). Every line is as high as the others (spec 10 §6.2: in the grid a
/// header takes a cell line). shortcut: each call walks the groups; keep the first line of each
/// if a folder with thousands of types scrolls slowly.
#[derive(Debug, Clone, Copy)]
pub struct Lines<'a> {
    pub spans: &'a [Span],
    pub per_row: usize,
}

impl Lines<'_> {
    fn per(&self) -> usize {
        self.per_row.max(1)
    }

    /// Lines of entries in group `g` (none while closed).
    fn rows_in(&self, g: usize) -> usize {
        let s = &self.spans[g];
        if s.collapsed { 0 } else { s.len.div_ceil(self.per()) }
    }

    pub fn count(&self) -> usize {
        (0..self.spans.len()).map(|g| 1 + self.rows_in(g)).sum()
    }

    pub fn line(&self, n: usize) -> Option<Line> {
        let mut first = 0;
        for g in 0..self.spans.len() {
            let lines = 1 + self.rows_in(g);
            if n < first + lines {
                return Some(if n == first { Line::Header(g) } else { Line::Cells(self.row(g, n - first - 1)) });
            }
            first += lines;
        }
        None
    }

    /// The line entry `index` is on and its column; `None` in a closed group or past the end.
    pub fn line_of(&self, index: usize) -> Option<(usize, usize)> {
        let mut first = 0;
        for (g, s) in self.spans.iter().enumerate() {
            if (s.start..s.end()).contains(&index) {
                let k = index - s.start;
                return (!s.collapsed).then_some((first + 1 + k / self.per(), k % self.per()));
            }
            first += 1 + self.rows_in(g);
        }
        None
    }

    /// The entries on lines `lines`: from the first to past the last (a closed group between
    /// counts in; headers have none).
    pub fn entries_on(&self, lines: Range<usize>) -> Range<usize> {
        let mut out: Option<Range<usize>> = None;
        for n in lines {
            match self.line(n) {
                Some(Line::Cells(r)) => out = Some(out.map_or(r.clone(), |o| o.start..r.end)),
                Some(Line::Header(_)) => {}
                None => break,
            }
        }
        out.unwrap_or(0..0)
    }

    /// The entries `rect` touches (content coordinates), as `Geometry::items_in_rect` does
    /// without groups; header lines have none.
    pub fn items_in_rect(&self, geometry: &Geometry, rect: Rect) -> Vec<Range<usize>> {
        let h = geometry.row_height();
        let (bottom, count) = (rect.y + rect.height, self.count());
        if count == 0 || h <= 0.0 || bottom <= 0.0 {
            return Vec::new();
        }
        let first = (rect.y.max(0.0) / h).floor() as usize;
        let last = ((bottom / h).ceil() as usize).saturating_sub(1).min(count - 1);
        if first > last {
            return Vec::new();
        }
        let columns = match *geometry {
            Geometry::List { .. } => None,
            Geometry::Grid { cell_width, left, .. } => {
                let (x, right) = (rect.x - left, rect.x + rect.width - left);
                if right <= 0.0 || cell_width <= 0.0 || x >= self.per() as f32 * cell_width {
                    return Vec::new();
                }
                let c0 = (x.max(0.0) / cell_width).floor() as usize;
                let c1 = ((right / cell_width).ceil() as usize).saturating_sub(1).min(self.per() - 1);
                Some((c0, c1))
            }
        };
        (first..=last)
            .filter_map(|n| match self.line(n)? {
                Line::Header(_) => None,
                Line::Cells(r) => match columns {
                    None => Some(r),
                    Some((c0, c1)) => {
                        let (start, end) = (r.start + c0, (r.start + c1 + 1).min(r.end));
                        (start < end).then_some(start..end)
                    }
                },
            })
            .collect()
    }

    /// Entries `r`'th line in group `g`.
    fn row(&self, g: usize, r: usize) -> Range<usize> {
        let s = &self.spans[g];
        let a = s.start + r * self.per();
        a..(a + self.per()).min(s.end())
    }

    fn next_row(&self, (g, r): (usize, usize)) -> Option<(usize, usize)> {
        if r + 1 < self.rows_in(g) {
            return Some((g, r + 1));
        }
        (g + 1..self.spans.len()).find(|&h| self.rows_in(h) > 0).map(|h| (h, 0))
    }

    fn prev_row(&self, (g, r): (usize, usize)) -> Option<(usize, usize)> {
        if r > 0 {
            return Some((g, r - 1));
        }
        (0..g).rev().find(|&h| self.rows_in(h) > 0).map(|h| (h, self.rows_in(h) - 1))
    }

    /// Where the focus goes from `from` for a key, as `Geometry::step` does without groups:
    /// lines of entries only (headers and closed groups are skipped). A focus in a closed
    /// group counts as none. `None` if no entry shows, or for Left/Right in the list.
    pub fn step(&self, from: Option<usize>, mv: Move, page_rows: usize, grid: bool) -> Option<usize> {
        let first_g = (0..self.spans.len()).find(|&g| self.rows_in(g) > 0)?;
        let last_g = (0..self.spans.len()).rev().find(|&g| self.rows_in(g) > 0)?;
        let (first, last) = (self.spans[first_g].start, self.row(last_g, self.rows_in(last_g) - 1).end - 1);
        let located = from.and_then(|i| {
            let g = self.spans.iter().position(|s| !s.collapsed && (s.start..s.end()).contains(&i))?;
            Some((i, (g, (i - self.spans[g].start) / self.per())))
        });
        let Some((i, at)) = located else {
            return match mv {
                Move::Left | Move::Right if !grid => None,
                Move::End => Some(last),
                _ => Some(first),
            };
        };
        let here = self.row(at.0, at.1);
        let col = i - here.start;
        let land = |(g, r): (usize, usize)| {
            let row = self.row(g, r);
            (row.start + col).min(row.end - 1)
        };
        let walk = |n: usize, down: bool| {
            let mut p = at;
            for _ in 0..n {
                match if down { self.next_row(p) } else { self.prev_row(p) } {
                    Some(q) => p = q,
                    None => break,
                }
            }
            p
        };
        let page = page_rows.max(1);
        Some(match mv {
            Move::Up => land(walk(1, false)),
            Move::Down => land(walk(1, true)),
            Move::PageUp => land(walk(page, false)),
            Move::PageDown => land(walk(page, true)),
            Move::Left if grid => {
                if i > here.start {
                    i - 1
                } else {
                    self.prev_row(at).map_or(i, |p| self.row(p.0, p.1).end - 1)
                }
            }
            Move::Right if grid => {
                if i + 1 < here.end {
                    i + 1
                } else {
                    self.next_row(at).map_or(i, |p| self.row(p.0, p.1).start)
                }
            }
            Move::Left | Move::Right => return None,
            Move::Home => first,
            Move::End => last,
        })
    }
}

/// selection, and a focus on one moves to the next row shown (the last one before it at the

pub fn hide_collapsed(data: &mut ViewData) -> Vec<Range<usize>> {
    let closed: Vec<Range<usize>> =
        data.groups.iter().filter(|s| s.collapsed).map(|s| s.start..s.start + s.len).collect();
    if closed.is_empty() {
        return Vec::new();
    }
    let mut changes = Vec::new();
    if data.selection.count() > 0 {
        for range in &closed {
            changes.extend(data.selection.unselect(range.clone()));
        }
    }

        let open = || data.groups.iter().filter(|s| !s.collapsed);
        let next = open()

            .map(|s| s.start)
            .or_else(|| open().filter(|s| s.start < focus).last().map(|s| s.start + s.len - 1));
        data.selection = std::mem::take(&mut data.selection).focused_at(next);
        changes.push(focus..focus + 1);
        changes.extend(next.map(|n| n..n + 1));
    }
    changes

    /// Opens or closes groups without reading or sorting anything (spec 10 §6.2): `change` gives
    /// a group's new state from its key and its state now. The scroll stays.
    fn collapse_where(&self, change: impl Fn(&GroupKey, bool) -> bool) {
        {
            let mut data = self.0.data.borrow_mut();
            let mut collapsed = self.0.collapsed.borrow_mut();
            let mut any = false;
            let ViewData { groups, group_keys, .. } = &mut *data;
            for (span, key) in groups.iter_mut().zip(group_keys.iter()) {
                let now = change(key, span.collapsed);
                if now != span.collapsed {
                    span.collapsed = now;
                    any = true;
                    if now {
                        collapsed.insert(key.clone());
                    } else {
                        collapsed.remove(key);
                    }
                }
            }
            if !any {
                return;
            }
            hide_collapsed(&mut data);
        }
        let scroll = self.list_scroll();
        self.0.model.notify.reset();
        self.keep_scroll_after_reset(scroll);
        if let Some(window) = self.0.window.upgrade() {
            self.sync_focus(&window);
        }
        self.update_status();
        self.notify_listeners();
    }

    /// A click on a group's header (its first entry `first`): the group opens or closes.
    pub fn toggle_group(&self, first: usize) {
        let key = {
            let data = self.0.data.borrow();
            data.groups.iter().position(|s| s.start == first).and_then(|g| data.group_keys.get(g).cloned())
        };
        if let Some(key) = key {
            self.collapse_where(|k, now| if *k == key { !now } else { now });
        }
    }

    /// Collapse All Groups (`true`) / Expand All Groups.
    pub fn collapse_all(&self, on: bool) {
        self.collapse_where(|_, _| on);
    }

    /// Group by ▸ (spec 10 §6.2); the folder remembers it.
    pub fn set_group(&self, by: GroupBy) {
        self.change_view(|v| v.group = by);
    }
