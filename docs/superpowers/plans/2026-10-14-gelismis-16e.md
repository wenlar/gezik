# Gelişmiş 16e (Git komutları) — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Depo içinde Stage, Unstage, Commit… (pencere), Push, Pull, Fetch, Switch Branch, Discard Changes… (önce çöpe, tek Ctrl+Z), Compare with HEAD (11'in karşılaştırması). Hepsi 16c'nin panel çalıştırıcısıyla; push/pull/fetch/commit paneli açar ve durdurulabilir, kısa olanlar yalnız hatada açar. Durum çubuğundaki Git yazısına tık menüyü açar (silinenlerin adları dahil). Aynı depoda tek komut (kuyruk); durum koşusu komut sürerken bekler, komut bitince bütün bölmeler yenilenir. Boşta 0, exe ≤ +262.144 B.

**Spec:** `docs/superpowers/specs/2026-10-13-gelismis-design.md` §9, §11.2, §11.3, §13, §14 16e; §18 karar 14, 15. 16d'nin sapma 3'ü (durum çubuğu menüsü, silinenlerin listesi) burada. Dal `feat/git-16e`, `feat/git-16d` üstüne yığılı.

## Bulgular

1. `command_line.rs` çalıştırıcısı kabuk komutu için; `spawn_piped` girdiyi boş verir. Commit iletisi ve uzun yol listesi girdiden gider: `spawn_piped_input`.
2. `gezik-ops` geri alması "aynı yere yeni dosya + eskisi çöpte" çiftini `SwapBackTask` ile geri alır (16b'nin arşiv yeniden yazması). Discard bir görev olarak `Trashed` + `Created` verirse tek Ctrl+Z eski dosyayı git'in yazdığının yerine getirir; ek kod yok.
3. Menüler: Windows'ta Explorer menüsüne alt menü sınırı yok; Gezik'in kendi menüsünde `MAX_SUBMENUS` = 5 (dolarsa Git öğeleri Tools ▸'un sonuna, başlıkla).

## Kararlar (soru sorulmadı)

1. **Güven:** her git çağrısı 16d'nin ortak güvenli yolundan (`git.rs`): ortam temizliği, istem yok, fsmonitor kapalı, deponun kendi süzgeç sürücüleri boş, aktarım yok. Ayrıklar: commit ve push kullanıcının hook'larını ve süzgeçlerini git gibi çalıştırır (spec §9.2); push, pull, fetch aktarımı yalnız `http:https:ssh:git:file` ile (`ext::` vb. yok).
2. Yollar kökten `/` ile, `GIT_LITERAL_PATHSPECS=1` (adda `*` ya da `[` desen sayılmaz); 32 KB'ı geçen liste `--pathspec-from-file=- --pathspec-file-nul` ile girdiden.
3. Switch Branch ▸ alt menü yerine ayrı bir menü (dallar bir git koşusuyla gelir; menü onlar gelince açılır).
4. Compare with HEAD `git cat-file --filters HEAD:<yol>` (git'in satır sonu çevirisiyle; `show` yerine: süzgeçsiz ham blob CRLF'li dosyada her satırı farklı gösterirdi).
5. Discard yalnız çalışma ağacındaki değişikliği ve izlenmeyeni atar; klasör seçilince içindeki değişmiş dosyalara açılır (yok sayılanlar çöpe gitmez).
