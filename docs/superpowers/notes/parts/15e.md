# 15e: Turkish translation (draft) — notes

`crates/gezik-i18n/lang/tr.po`: all 2,787 texts of `gezik.pot` translated, built in by `build.rs`. Terms and style from `../tr-glossary.md`; for its 22 debatable choices the first choice is used.

## What is in

- **Header:** `Language: tr`, `Plural-Forms: nplurals=1; plural=0;` (one `msgstr[0]` per plural), `X-Gezik-Name: Türkçe`, `X-Gezik-Number: decimal=",", group="."`, `X-Gezik-Review: draft`.
- **Review state:** machine-assisted, for the maintainer to review. `draft` is not `machine`, so the code treats the file as reviewed (`human`): every text must be there (it is), and Settings shows no "machine translated" note. No entry is `#, fuzzy`: the 11 entries that were unclear were checked against the code and settled (below). Switch to `machine` + `fuzzy` only if the review should show in Settings.
- **Test:** `catalog::tests::pseudo_and_nothing` asserted "no built-in languages yet"; it now checks that `tr` opens and translates "Open" to "Aç".
- **Placeholder order:** every text with two or more `{}` keeps the source order, or uses `{0}`/`{1}` where Turkish word order differs (e.g. "Search for \"{}\" in {}" → "{1} içinde \"{0}\" ara"; also "Move {} items on {} to the Recycle Bin/Trash", "{} files on {} would be replaced…", "More than {} items in {}…", "Sync browsing off: no folder \"{}\" in {}", "Page {} of {}, go to page").

## Choices to review

- **Literal settings values stay English** inside messages and setting descriptions: `true`/`false`, `auto`, `none`, `left | right | hidden`, `[[commands]]`, colour names in `settings.toml` errors. Users type them that way.
- **Progress / admin lines** use colon and arrow forms to avoid suffixes on placeholders: "Kopyalanıyor: {0} → {1}", "Kopyala: {} → {}", "Yeniden adlandır: {} → \"{}\"". "{} konumuna" / "{} klasörüne" are used where a separate word carries the suffix.
- **Trash inside sentences** is "çöpe" / "çöpte"; the noun on its own is "Çöp Sepeti".
- **Tray:** "bildirim alanı" on every platform, including the Linux-only texts (the source says "tray" there; "sistem tepsisi" would be the Linux habit).
- **Load** → "yüklenemedi" ("pdfium yüklenemedi") sits next to Install = "Yükle".
- **Genre** → "Tarz" (Type is "Tür"); size groups Gigantic/Huge/Tiny → "Dev"/"Çok büyük"/"Çok küçük".
- **Edit menu** "Düzenle" (Layout is "Düzen"); compression level Store → "Depola" (7-Zip's word); convert From/To → "Kaynak"/"Hedef".
- **Hide {} / Show {}** (column toggles) → "Gizle: {}" / "Göster: {}".
- **Rename preview row's accessible label** "{} to {}" → "{}, yeni ad: {}".
- **"Exported on {}"** ({} is the OS) → "Dışa aktarıldığı sistem: {}."; **"{} replaces"** (settings import preview) → "{} değişecek".
- **"4.7 GB"** in a size example keeps the dot; whether the size parser takes "4,7" was not checked.
- **Quick Look**: "hızlı bakış" in running text, but one setting description writes "Hızlı Bakış paneli" for the macOS system panel.
