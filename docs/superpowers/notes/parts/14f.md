# 14f: sync folder — notes

Plan `../../plans/2026-10-12-tasinabilirlik-14f.md`, spec §3.1, §8, decisions 11, 12, 15. Step 14 is complete with this part.

## Follow-ups

- **The shared folder moves at run time**: the store keeps it behind a mutex shared by its clones and the settings writer; setting up or leaving the sync folder needs no restart (files, `set_shared`, the watcher's `follow`, a reload).
- **A typed path instead of a folder picker** for Keep Settings in a Folder, as Export and Import (14d); a cloud folder found by the places is suggested in the description.
- **No clickable Review… in the status bar**: the notice is plain text; it says "Review it in Settings > Sync and Backup", where each copy has a Review… row.
- **Themes are merged key by key too** (the spec only asked for their copies to be recognised), with the same re-check before the write.
- **OneDrive's `settings-<COMPUTER>.toml`** is recognised for the computers in the folder's `machines/` (an empty file per computer, written at setup: no two computers write the same file). A computer renamed after setup is not known by its new name until it sets the folder up again.
- **Only `Value`, `System` and `Local` changes follow settings.local.toml**: a View menu option, pins or the lists always go to the shared file (shortcut: a key also in settings.local.toml keeps winning there).
- **mtime granularity**: two writes of the same size within one timestamp tick (FAT: 2 s) are not told apart; the conflicting-copy review is the net for that.
- **A folder whose parent is also gone** (a USB drive) is not watched; Check Again on its row looks again. Nothing polls.
- **Changes made while the folder is away** are kept in memory (pins stay shown) and written at the first reload that finds it; they are lost if Gezik quits first (the row says how many wait).
- **Templates are never written over** when setting up or leaving the folder (only missing ones are copied), so backups never need them.
- **The 14e `shortcut:` note in `settings_backup.rs` is resolved**: `Folders { shared, local }`; views.toml and `backups/` are this computer's.
- **No new actions**; menu id 2813 (Only on This Computer / Use the Shared Value) in the row menu.
- **Checklist numbers** go on from 14e: macOS 376–378, Linux 273–274.
- **Windows GUI test** not run (no GUI while the user is at the PC).
