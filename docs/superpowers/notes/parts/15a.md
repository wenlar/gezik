# 15a: localisation machinery — notes

Plan `../../plans/2026-10-13-yerellestirme-15a.md`, spec §4, §5, §9, §11, §13.2 15a.

## What is in

- **`crates/gezik-i18n`** (only `miniz_oxide`, already linked): `.po` reader and writer (`po`), plural rules with a `Plural-Forms` evaluator (`plural`; no loops, length ≤ 512, nesting ≤ 64), Slint's placeholder syntax (`format`), the pseudo language (`pseudo`), language codes and the system match (`lang`), layers and the catalogue (`catalog`), a file's checks (`check`), the packed form of built-in languages (`blob`, `build.rs`), the language in use and `t!`/`tn!`/`tx!` (`lib`).
- **English loads nothing**: the language in use is `None`, `t!` copies its text; Slint gets no translator. Only the selected built-in language is inflated (`Catalog::open`); there are none yet (`BUILTINS` is empty, the format is round-tripped in a unit test).
- **Slint**: `i-slint-core` is a normal dependency with `tr`; `translator.rs` hands Slint an `Arc<Catalog>` (borrowed `Cow`s), `set_external_translator` re-evaluates every `@tr`. `tests/slint_translate.rs` includes the same file and checks a binding before and after.
- **System language**: `gezik_platform::preferred_languages()` (Windows `GetUserPreferredUILanguages`, macOS `NSLocale.preferredLanguages`, Linux gettext's variable order, pure and tested), read once.
- **`language`** (top of `settings.toml`, General page, `Kind::Language`): choices `code — name` (`auto — System: English`, `pl — Polski — 0 % translated`, `pseudo — Pseudo (for translators)`); the code is written. An invalid code is a parse warning, an unknown one a resolve warning ("no such language, using the system's").
- **`lang/*.po`** in the shared settings folder: read, parsed and checked by `ConfigStore::read_files` (off the UI thread on reloads), ≤ 4 MB, ≤ 10 problems per file in the notices, then "N of M texts missing". The watcher already watched the folder recursively; `is_config_file` now counts `lang/*.po`.
- **`gezik-lang`** (`cargo run -p gezik-i18n --bin gezik-lang -- extract | update | check`): extract reads `t!`/`tn!`/`tx!` (strings, comments, raw strings and char literals skipped; stops at a file's `#[cfg(test)]`; `// TRANSLATORS:` notes) and Slint `@tr` (with `\{…}` interpolations skipped). `cargo test -p gezik-i18n` fails when the pot is stale, when two keys share a hash, or when a built-in `.po` has errors (or misses texts while `human`).
- **Texts translated so far** (to prove the pipe): the language row's labels (`t!`) and the Settings window's title (`@tr`). Everything else waits for 15b/15c.

## Follow-ups

- **`number.rs` moved to 15c** with the other formats: `{n}` is a plain number for now.
- **Settings template comments** go into the pot in 15b, with the settings window's titles and descriptions.
- **Offline sync folder**: `lang/` is not copied to `sync-cache/`; while the folder is away a dropped language shows English (`shortcut:` in `store.rs`).
- **"N of M texts missing"** is a notice at every reload for an incomplete dropped file, as the spec asks; if it nags, show it only in the language row.
- **`fuzzy` counts** for a dropped file are those of usable entries; entries with errors count as missing.
- **Pseudo frame characters** `⟦ ⟧` (U+27E6/7) rely on the system's font fallback; the checklists ask to look for empty boxes.
- **Windows GUI test** not run (no GUI while the user is at the PC).
