# 14c: themes from GitHub — notes

Plan `../../plans/2026-10-12-tasinabilirlik-14c.md`, spec §6.

## Follow-ups

- **Colour strip:** the spec's accent/background/text strip in each found theme's row was left out for the exe budget; the preview (pointing at Install/Replace/Keep Both) shows the whole theme instead. Add it if the screen test finds the rows hard to tell apart.
- **Checkboxes and one Install:** themes are installed one by one from their own rows (no multi-select). A repository with many themes needs one choice per theme.
- **"Use it now?" after a single install:** the status line points at the installed row's `Use Now` instead of asking.
- **Unknown keys of a found theme** are not listed; the row counts only the values Gezik skips (wrong type or out of range).
- **Branch names with `/`** in `…/tree/<branch>/…` read the first segment as the branch (GitHub's addresses cannot tell them apart without the API).
- **Download cancel:** a new address, an empty address with Return, or closing the window stops it; there is no Cancel button.
- **Delete Theme** goes through the normal trash (and its confirmation setting), with undo.
- **Windows GUI test** (not run: the user was gaming): see the checklist in the PR.
