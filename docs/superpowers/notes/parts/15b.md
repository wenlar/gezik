# 15b: the interface's texts — notes

Plan `../../plans/2026-10-13-yerellestirme-15b.md`, spec §4.2, §4.5, §6, §7, §10.2, §13.2 15b.

## What is in

- **Slint:** every visible text of the 32 `.slint` files goes through `@tr` (~360 places, the
  79 accessibility names included). Texts that were put together from pieces are one `@tr`
  with placeholders (`"{} — Gezik"`, `"Remove {}"`, `"Page {} of {}"`, `"{}, tags {}"`); the
  picker's stars are a plural. Contexts only where one English word means two things:
  `column` (file list headers), `button` (the conflict list's Replace and Start), `unit` (MB),
  `case` (rename's UPPER/Title/Sentence/lower).
- **Slint check:** `gezik-lang`'s `slint_texts_are_marked` reads every string literal of the
  `.slint` files outside `@tr`, `@image-url` and imports; one with a letter fails unless it is
  an id (`new-window`, `tag:`), an SVG path, `{token}`s only, or kept as it is (`Gezik`, PNG,
  JPEG, LF, CRLF, CR, A4). A lower-case word with no space is taken for an id (limit).
- **Rust:** action titles (`Action::title`, `tx!`, shown with `t`), System Integration
  commands in the palette, menus (`context_menu.rs`, `archives.rs`, `copy_to.rs`, `convert.rs`
  menu items, `tags.rs`), the tray menu, the pickers' labels (palette, tabs, tags, fields,
  System Integration), the sidebar's headings and tips, the shortcuts page, the conflict
  list's decisions, core labels shown in menus (`DateFormat`, `SizeFormat`, `KindFilter`,
  `PathFormat`, `GroupBy`, `TagColor`, `Decision`, rename rule kinds, palette tags; marked with
  `tx!` in gezik-core, so gezik-core and gezik-platform now depend on gezik-i18n).
- **Palette:** a translated title is also found by its English one (`Item::also`, folded after
  the title, so "starts with" ranks by the shown title).
- **Settings window:** the fields, pages and the template's line reader moved to
  `gezik-config/src/schema/table.rs` (std and `tx!` only), which `gezik-lang` includes with
  `#[path]`: `extract` writes each field's title and description (the template comment) with
  the context `setting:<path>`. The comment after a value is read by a small reader there
  instead of toml_edit (a test compares the two on every template line). Choices are
  `tx!("choice:<path>" => "value")`: the row shows the translation, the value written stays
  English (mapped back from the label). Backup and theme rows: titles, values, descriptions
  and options translated; a chosen option is mapped back to its English const
  (`source_of`). Search finds English and translated titles and descriptions.
- **macOS app menu:** muda wrote About/Services/Hide/Hide Others/Show All/Quit in English; a
  vendor patch (`i-slint-backend-winit` 5, `vendor/README.md`) takes Gezik's texts before the
  first window. A language change shows there at the next start, like AppKit's own items.
- **Language change:** goes through `apply_config` (sidebar, menu bar commands and tags);
  Settings rebuilds its pages and rows on `refresh`; the tray's menu is rebuilt
  (`resident::refresh_pins`); right-click menus and the palette are built when opened.
- **Tests:** Slint check; every field title, description, choice, page and action title in
  the pot, an action title framed in the pseudo language (gezik-config); hint reader = toml_edit.
- **Pot:** 948 texts (121 of them the settings window's `setting:` titles and descriptions).

## Pseudo-language pass (static; the GUI was not run)

Untranslated texts: none left in `.slint` (the test). In Rust, what stays English on purpose
until 15c: status lines, prompts and questions (`ask`, `ask_text`), errors, the System
Integration window's rows and questions, the tools (compare, checksums, convert, batch rename
tables, info), field labels from `gezik-core` (`fields.rs`: column and property names,
`Sort by {}…` still lower-cases the English label), date/size formats, known folder names.

Overflow candidates (fixed widths that hold a translated text; ~40 % longer in pseudo):

- compress and convert `Labeled` labels, 88 px (Password, Background, Line endings,
  Resolution, Preset); info 80 px (Owner, Group, Your groups, Octal, Open with); rename-batch
  72 px (Separator, Extension, Digits).
- info permission checks, 84 px each at fixed x (Read, Write, Execute, Hidden, Locked).
- compress level buttons, min-width 64 px (Store, Fast, Normal, Best).
- conflict list: Source/Target headers 200 px, `(newer)` lines 200 px (elided), Action 110 px.
- tool table's Status header 110 px; convert's Quality field 72 px, Background 96 px.
- settings rows: the control column is 240 px (choice labels elide).

## Follow-ups

- **Pane's Filters button** text is set from Rust when the pane is made and when the search
  draft changes: after a language change it stays in the old language until then.
- **Spoken lists** (settings row's spoken text, conflict row's `· identical`) join translated
  words with commas or dots: a list, not a sentence; pseudo shows several frames there.
- **15c:** see the list above; `items_text`/`count_text` counts inside 15b's texts
  (`Tags for {}`) are 15c's plurals.
