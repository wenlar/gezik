# 14e: shared and local folders, portable mode — notes

Plan `../../plans/2026-10-12-tasinabilirlik-14e.md`, spec §3.1, §9.

## Follow-ups

- **A `gezik-data` that cannot be made** (a marker on a read-only drive without the folder) falls back to the usual config folder with a status bar note; one that is there but read-only is used read-only (`keep_state_unwritten`, no first-run files). The spec described only the second.
- **Writability is probed** with a file made and removed at once, only when a marker is there (no marker: one `metadata` call, as the spec budgets).
- **Export, import and backups still use one folder** (the store's shared one, `views.toml` and `backups/` included): right while shared and local are the same folder; 14f splits them (`shortcut:` note in `settings_backup.rs`).
- **The journal is named by the computer's id** (review): `MachineGuid`, `IOPlatformUUID` or machine-id, hashed to 12 hex digits; the host name only when the id cannot be read, and inside the file as `machine`. A journal of this host (by `machine`, or named by the host as 14e's first build did) is taken over only when it is the single one; the coordinator suggested taking any single other journal, which would hand one computer's changes to another (decision 14), so it is limited to this host's.
- **The exe path is canonicalized on Windows too** (without `\\?\`): a junction or `subst` drive to the same portable folder gives the same single-instance key; a mapped drive shows as its `\\server\share` path.
- **The journal's lock file** stays `system-changes.lock` for every machine (one drive is not used on two computers at once). Messages still name `system-changes.toml`; the row shows the real path.
- **Downloaded tools** now take the tools folder itself (`gezik_batch::tools::install_dir(build, tools)`); without a marker that is `tools/` in the config folder as before, so nothing moves.
- **No new actions or menu ids** (spec §10.2): the Sync and Backup page's first row (portable only) and its `Open Data Folder`.
- **Checklist numbers** go on from 14d: macOS 374–375, Linux 271–272 (the spec's 398–399 and 287–288 were written before the numbering moved).
- **Windows GUI test** not run (no GUI while the user is at the PC).
