# 15d: CJK font fallback — notes

Plan `../../plans/2026-10-13-yerellestirme-15d.md`, spec §3.4, §13.2 15d, decision 12.

## What is in

- **Vendor patch** (`vendor/i-slint-core/textlayout/sharedparley/shaping.rs`, see `vendor/README.md`): a per-thread `Property<Option<Language>>` set by `sharedparley::set_text_locale`, pushed as parley's `StyleProperty::Locale` for all text. Read while shaping, so the text layout cache entries depend on it: a change reshapes every text once, nothing per frame, no cache key.
- **The language** (`gezik_i18n::lang::text_locale`, pure): the interface language if Chinese, Japanese or Korean (a dropped `ja.po` counts), else the system's first CJK language (`ja-JP`, `zh_TW.UTF-8` → `zh-TW`), else `zh-Hans`. `language::apply` sets it on every config apply, before its early return (the start's English would skip it) and before the first frame.
- **Why boxes:** on Windows fontique's Han fallback without a language (and for `ja`) is Yu Gothic UI, `zh-Hans` Microsoft YaHei UI, `zh-TW` Microsoft JhengHei UI, `ko` Malgun Gothic. Yu Gothic has no Simplified-only characters (`这`, `对`), and parley then draws them with the first family (Arial): an empty box.
- **Test** `crates/gezik/tests/slint_cjk.rs`: `这` and `日` are drawn with Microsoft YaHei UI in `zh-Hans`, `日` with Yu Gothic UI in `ja` (Windows), PingFang/Heiti vs Hiragino (macOS), printed only on Linux; Latin text's fonts do not depend on the language; a cached shaping is invalidated when the language changes.

## Follow-ups

- **Linux note "Install a Chinese font (e.g. Noto Sans CJK SC) to show this language"** (spec §10.3) moves to 15f, where `zh-Hans` becomes selectable.
- **fontique shares one fallback slot between no language and Simplified Chinese** and fills it on the first query: a Han text shaped before `apply_config` would pin Yu Gothic. Nothing draws before it today; keep `language::apply` first.
- **Latin text also gets the CJK language** (harfrust's `locl`): no change from today (no language), but Turkish `locl` forms are not used. Passing the interface language for non-Han runs would need per-script styles in parley.
- **Japanese file names on a non-Japanese system** draw their Kanji in the Chinese font (one language for all text, decision 12); a Japanese system or interface keeps Japanese forms.
