# The split View toolbar (design 3a) on macOS: manual checks

Numbering goes on after `17-macos.md` (502). Results go to `../macos-test-results.md`. Notes: `../parts/view-menu-3a.md`.

503. **The toolbar.** Right of the address bar: Layout (the list's three lines + ▾), Sort ("Name" + ▾), a short divider, Preview pane, Two panes, ⋯. Nothing is cut off in a 900 px window; in light and dark themes the buttons and popups take the theme's colours.
504. **Layout popup.** Click Layout: a 300 px popup under it with "Layout", List | Grid | Columns, Icon size (greyed in the list), Flat view switch, and "⇧⌘1 / ⇧⌘2 / ⌃⌘3 switch layout". Choose Grid: the folder turns to a grid, the popup stays open with Grid chosen and Icon size usable; Large makes the icons bigger. The button's icon follows the layout. Flat view on and off works and the switch follows. Esc or a click outside closes it.
505. **Sort menu.** Click Sort: the button looks pressed (accent border) while the menu is open. "Sort by", the eight keys with ✓ on the current one, ↑ Ascending | ↓ Descending, Group by with its value and ›, Folders first ✓. Choose Size: the list sorts by size, the button says "Size". Descending flips it. Property… opens the property picker; after choosing Duration, the button says "Duration".
506. **Group by.** In the Sort menu click Group by ›: Gezik's own menu (not a system one) opens beside it with None, Type, Date, … and the properties; Type groups the list. Open it again: Collapse All Groups and Expand All Groups are at its end.
507. **⋯ menu.** Show hidden items (⇧⌘.), Show file extensions, Calculate folder sizes (only in a folder, not in This Mac or search results); Use this view everywhere, Reset this folder; Show in sidebar tree, Settings… (⌘,), System Integration…. No Show system items on macOS. Each does what the old View menu item did; the ✓ marks follow.
508. **Panel toggles.** Preview pane opens and closes the preview; it is lit while open. Right-click it: Right / Bottom, the current one marked and greyed; Bottom moves the preview under the list. Two panes opens the second pane (lit); right-click: Side by side / Stacked.
509. **Between the panes.** With two panes side by side, the link between the address bars is shown dimmed; a click turns sync browsing on (accent) and off. The ⋯ menu now also has Sync browsing ✓, Swap panes (with its shortcut) and Same folder in other pane, which work. A pane narrower than 400 px shows the Sort button without its name and no divider.
510. **Status bar.** "Drop stack" is beside History: a click shows and hides the stack, lit while it is shown.
511. **Keyboard.** Tab to Layout and press Space: the popup opens; ↓/↑ move through the layouts, sizes and Flat view, Return chooses. In the Sort and ⋯ menus ↓/↑ skip the heading and dividers, Return on Group by opens its menu. Closing any of them gives the keyboard back to the list.
512. **The menu bar.** The View menu at the top of the screen is still there and works as before (it is macOS's global menu).
